# PFA Scout Messenger

כלי מקומי של Premier Football Agency לשליחת הודעות WhatsApp אישיות לסקאוטים מתוך קובץ אקסל, בלי לשמור את המספרים באנשי הקשר.

## דרישות מוקדמות
- Python 3.10 ומעלה
- דפדפן Google Chrome מותקן (את ה-ChromeDriver מוריד Selenium אוטומטית)

## התקנה והרצה
```bash
cd pfa_scout_messenger
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
python -m streamlit run app.py
```
הממשק נפתח בכתובת http://localhost:8501.

## איך זה עובד
1. נפתח חלון Chrome עם WhatsApp Web. סורקים את קוד ה-QR (פעם ראשונה בלבד: הסשן נשמר בתיקייה `chrome_profile/`).
2. לכל סקאוט: `{name}` מוחלף בשם, בתחילת ההודעה מתווספת ברכה אקראית, והצ'אט נפתח דרך `web.whatsapp.com/send?phone=...&text=...`.
3. השליחה מתבצעת בלחיצה על כפתור השליחה. אם WhatsApp לא מגיב ללחיצה, התוכנה שולחת ב-Enter. השיטה שעבדה מופיעה ביומן.
4. אחרי כל שליחה מוצלחת יש השהיה אקראית של 25 עד 45 שניות.
5. מספר שלא נטען בזמן (למשל מספר בלי חשבון WhatsApp), או הודעה שלא יצאה, נרשמים ככישלון, והתוכנה ממשיכה לשורה הבאה.
6. בסיום מוצג סיכום, ואפשר להוריד דוח CSV.

## חשוב לדעת
- **סיכון לחסימה:** תנאי השימוש של WhatsApp אוסרים שליחה אוטומטית. ההשהיות והברכות האקראיות מקטינות את הסיכון אבל לא מבטלות אותו. סיכון גבוה במיוחד: מספר חדש, הרבה הודעות ביום, ונמענים שמדווחים על ספאם. מומלץ לשלוח רק לאנשים שמצפים לפנייה.
- **שינויים ב-WhatsApp Web:** אם WhatsApp ישנו את מבנה הדף, השליחה תיכשל ב-Timeout. במקרה כזה צריך לעדכן את `SEND_BUTTON_XPATH` ו-`COMPOSER_XPATH` בראש `app.py`.
- **פרטיות:** התיקייה `chrome_profile/` מכילה את סשן ההתחברות לחשבון. אין לשתף אותה או להעלות אותה ל-git (היא כבר מוחרגת ב-`.gitignore`).
- **במהלך הריצה** אין לגעת בחלון הכרום, ואין לשנות שדות בדף: כל שינוי עוצר את הריצה.
